## Operational additions / 2026-09-21

- **LINK-BASED SAVE SYNC**: A new user chooses `LOCAL ONLY`, `PRIVATE LINK SYNC`, `SELECTIVE SAVE LINK`, or `NO SYNC / LATER`. With link sync, the user keeps the SAVE in their own storage and shares a link. The common index stores the link and verification states, not a public copy of the personal SAVE. Treat the link as an incoming delta. Verify identity, schema, provenance, permissions, PAUSED, conflicts, and deduplication before creating a new version.

- **SHORT FIRST NORMALIZED**: Lead with the outcome and the minimum detail required for correctness, safety, and completion. Deliver a directly requested complete report or artifact without another gate. Do not expand optional detail automatically. Use the binary expansion gate only for an intentionally short Mode A layer.
