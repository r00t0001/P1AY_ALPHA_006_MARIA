# Обновление без потери SAVE

1. Сохраните исходные CORE и SAVE, их версии и хэши. Проверьте восстановление резервной копии.
2. Установите новый пакет в отдельную папку. Персональную базу и ключи храните вне репозитория.
3. Подтвердите владельца по независимому реестру. Совпадения имени файла недостаточно.
4. Команда `migrate` упакует известный SAVE_02/03/04 без потери полей в миграционный контейнер. Исходный объект, неизвестные расширения, история, разрешения, handshake и PAUSED сохраняются. Это подготовка к разбору, а не автоматическое превращение старого SAVE в полный SAVE_04.
5. Недостающие поля и противоречия разбираются явно. Неизвестный формат остаётся изолированным. Шаблон не заменяет личное состояние.
6. Новая версия проходит этапы: проверенный источник → событие → проверка → отдельное подтверждение с evidence → применение. Повторное событие не дублирует результат.
7. Подключите второе устройство и дождитесь его собственного подтверждения применения. До этого состояние — «локальная версия; подтверждение второй стороны ожидается».
8. Запишите версию установленного пакета на каждом устройстве. Новый репозиторий сам не обновляет старые чаты и скачанные CORE.

Для отката восстановите проверенную резервную базу в новый путь и сравните версии. Не перезаписывайте живую базу и не удаляйте более новую историю. Общий импорт не возобновляет PAUSED.
