# Security Policy

JULIA 007 is a text protocol and local validation toolkit, not a hosted service. Privacy labels are not encryption, and this repository must never contain real participant profiles, personal SAVE files, credentials, correspondence or private evidence.

## Reporting

Do not open a public issue containing personal data, secrets or an exploit transcript. Use GitHub's private vulnerability-reporting channel for the repository when available. Otherwise contact the repository owner privately and share only the minimum reproducible evidence.

Include the affected file or rule, exact release SHA-256, reproducible symptom, impact, and the minimum condition for clearance. Remove credentials and personal data from examples.

## Release blocking

Critical privacy, security, identity, data-loss or irreversible-migration findings block the affected component. Clearance requires a fix or scope exclusion plus an independent technical review. A failed gate cannot be relabeled PASS.

Only the current prerelease is considered for fixes. Historical artifacts remain evidence and are not silently replaced.
